# RAG Architecture

## In RAG
Diagnostic definitions, gate policies, strategy theses/eligibility, source hierarchy, portfolio/rotation/profit-taking policy, accepted research/governance notes.

## Not current truth in RAG
Latest prices, latest financial statements, current news, live portfolio balances, current market regime, or credentials.

## Retrieval
Retrieve only knowledge relevant to the current task/strategy.

## Version metadata
Every artifact: id, version, status, provenance, effective date, supersedes.
