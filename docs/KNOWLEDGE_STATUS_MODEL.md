# Knowledge authority and Lite lifecycle

Authority classifications are `AUTHORITATIVE_ACCEPTED`, `LATEST_ACCEPTED_WITH_LIMITATIONS`, `PROPOSED_NOT_ACTIVE`, `HISTORICAL_ONLY`, `OBSOLETE_OR_SUPERSEDED`, `CONFLICT_REVIEW_REQUIRED`, and `NOT_FOUND`. Lite lifecycle states are `INVENTORIED`, `EXTRACTED_DRAFT`, `REVIEW_REQUIRED`, `APPROVED_FOR_LITE`, `ACTIVE`, `INACTIVE`, `QUARANTINED`, and `SUPERSEDED`. `status` in the artifact envelope and `lifecycle` in a type profile denote the same Lite state and must match.

Allowed progression: `INVENTORIED → EXTRACTED_DRAFT → REVIEW_REQUIRED → APPROVED_FOR_LITE → ACTIVE`. A reviewer may send any pre-active state to `QUARANTINED`; a quarantined item returns only to `REVIEW_REQUIRED` after the blocker is resolved and documented. `ACTIVE → INACTIVE` is a controlled deactivation; `ACTIVE` or `INACTIVE → SUPERSEDED` requires a named reviewed successor. `INACTIVE → ACTIVE` requires renewed review, authority and effective-time checks. No state skip is implicit. Transition history, reviewer identity and version selection are registry concerns, not provable from a single JSON document.

Only accepted authority classes may reach `APPROVED_FOR_LITE` or `ACTIVE`. `ACTIVE` additionally requires `extraction_status=VERIFIED`, `review_status=HUMAN_APPROVED`, a non-null `effective_from`, and no blocking unresolved conflicts. `PROPOSED_NOT_ACTIVE` cannot transition directly—or indirectly without a new authority decision—to `ACTIVE`. Historical, obsolete, missing and conflict-review items remain inactive/quarantined. Missing evidence is UNKNOWN/UNAVAILABLE, not PASS.

Rule 35 is reserved for `CONFLICT_REVIEW_REQUIRED` + `QUARANTINED`: named VWAP/value-area semantics are not proven by the generic fallback. Rule 57 carries Task #002 audit classification `UNKNOWN_NEEDS_EXTRACTION` + `QUARANTINED`; canonical event, known-at and completed-session authority remain unresolved. `UNKNOWN_NEEDS_EXTRACTION` is an audit classification, not an authority-status enum; future Rule 57 authority must be reviewed before any promotion. Neither rule is materialized here.
