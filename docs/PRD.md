# PRD — HSI Agent Lite

## Users
Owner + approximately 10–12 invited trusted members.

## Initial surfaces
Home, Analyse, Scan, Watch, Portfolio.

## Analyse output
Company/symbol, data timestamp, HSI 10-point score, diagnostic summary, six gate states, matched strategies, technical evidence, fundamental evidence, news/catalyst evidence, market/sector context, liquidity/exitability, risk flags, Entry/SL/T1/T2/Extended, thesis, invalidation, citations/provenance, and confidence with limitations.

## Scan
Use deterministic filtering first; reserve expensive LLM research for finalists.

## Watch
Watch-only initially. No automatic broker order execution.

## Portfolio
Holding health, trim/profit-taking flags, deterioration flags, rotation comparisons, concentration/risk.

## Non-functional
Invite-only auth, user portfolio isolation, source timestamps, reproducible calculations, testable rule outputs, bounded AI cost.
