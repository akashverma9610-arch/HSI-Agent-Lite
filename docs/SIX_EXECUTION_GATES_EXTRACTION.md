Legacy `six-gates-production-v1 / v1` is the selected active six-gate policy at `f88b44d514fc9a2654040aa04e5350fc9e8660fe`; these Lite copies are `REVIEW_REQUIRED` knowledge, not active Lite runtime. Authority: `docs/EXECUTION_GATES.md`, `app/gates/production_policy.py#approved_v1_policy`, `app/gates/engine.py`, and gate tests. The six canonical IDs are `GATE_1_ROTATION`, `GATE_2_VELOCITY`, `GATE_3_SURVEILLANCE`, `GATE_4_TRADE_PLAN`, `GATE_5_HEAT`, `GATE_6_EARNINGS`. Exact selected V1 constants and condition boundaries are recorded in the six artifacts; descriptive ranges in documentation are not substituted for selected production values. For example, selected V1 uses a 1.00 score-point rotation hurdle, 12 trading sessions/1.0 ATR inactivity, 4 trading-session surveillance freshness, 0.50 initial and T1 reduction, 6% heat/25% stock/35% sector caps, and five trading-session pre-earnings blackout.

Every gate is an independent admissibility constraint. Gate 1 consumes canonical scorecards and modeled economic inputs for `ROTATE_IN` only; Gate 2 examines existing holding velocity and records a separate -0.50 rotation comparison adjustment without changing raw Decision Score; Gate 3 requires fresh authoritative complete ASM/GSM/price-band observations; Gate 4 consumes a governed analytical TradePlan (missing plan is **FAIL** in V1); Gate 5 consumes portfolio snapshot/exposure; Gate 6 consumes a verified earnings schedule for fresh/add/rotation contexts and does not prohibit existing-position risk management. The legacy reducer makes any FAIL `BLOCKED`; otherwise any `INSUFFICIENT_DATA` yields `INSUFFICIENT_DATA`; only all PASS yields `EXECUTABLE` classification. This does not create an order. Unknown/unavailable source and unresolved configuration cannot be treated as PASS. Historical known-at, effective selection, source authority, version compatibility and freshness remain prerequisites; current observations cannot silently certify historical decisions.

`GATE_DEPENDENCY_MAP.json` deliberately leaves direct Dxx dependencies empty: the V1 gate engine consumes typed GateInput fields, scorecards, source observations, setup and portfolio state, not Dxx outputs directly. Gate 2's ATR and Gate 4's entry/stop/target/risk-reward families are normalized Task #005 evidence references. External surveillance and earnings source contracts are not falsely relabeled as diagnostic evidence. The conceptual path is normalized evidence → 61 diagnostics → score, **plus** six independent gates → strategy evaluation → final governed synthesis, not score deciding everything. A high score cannot override a gate FAIL; gate PASS does not imply stock quality. None of these artifacts has strategy, sizing, portfolio-mutation or broker-order authority.
