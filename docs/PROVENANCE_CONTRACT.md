# Provenance contract

Every migrated artifact must include `id`, `name`, `artifact_type`, `version`, `status`, `effective_from`, `supersedes`, `legacy_repository`, `legacy_commit`, `legacy_sources`, `authority_status`, `extraction_status`, `review_status`, `calculation_owner`, `evidence_dependencies`, `known_limitations`, `conflicts`, and `notes`. The schema also requires `deterministic_computation` and `details`. `legacy_repository` identifies the read-only legacy repository; `legacy_commit` is a full immutable SHA, not a branch name. Each `legacy_sources` entry has `path`, `symbol_or_heading`, `authority`, and `source_role`. Source authority and artifact authority are separate: code implementation or a recent filename is not approval.

`effective_from` is null until a reviewed activation time exists. `supersedes` is an explicit list; a newer version does not silently displace an older active version. Empty `legacy_sources` are prohibited for migrated artifacts. `conflicts` names unresolved competing sources/semantics and a disposition; none may be hidden by narrative. Limitations remain visible to every consumer. `review_status=HUMAN_APPROVED` records review of the specific artifact version, not blanket approval of a domain.

Only `AUTHORITATIVE_ACCEPTED` or `LATEST_ACCEPTED_WITH_LIMITATIONS` can support `ACTIVE`, and then only after verified extraction, human approval, an effective time, an accepted approval/contract source, and closure of blocking conflicts. A proposal, historical draft, superseded source, unresolved conflict or missing authority cannot be promoted by an LLM, score, successful test, or schema-valid JSON. The JSON Schema enforces the static portion; a versioned registry must also enforce unique identity, source verification, transition history, profile/envelope consistency and the absence of unresolved blocking conflicts before activation.

Legacy baseline for this contract: `Hybrid-Stock-Intelligence` at `f88b44d514fc9a2654040aa04e5350fc9e8660fe`. It is a provenance pointer, not copied code or authority to activate every item.
