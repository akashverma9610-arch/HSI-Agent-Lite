# HSI Agent Lite

Private AI-assisted stock intelligence system for the owner and approximately 10–12 trusted users.

## Core principles
- **AI interprets; code calculates.**
- **RAG defines knowledge; live data defines facts.**
- **Calculate once → normalize once → reuse everywhere.**

## Non-goals
- No live broker order execution.
- No public SaaS launch in the initial scope.
- No enterprise multi-tenancy or billing.
- No modification of the legacy `Hybrid-Stock-Intelligence` repository.
- No autonomous strategy mutation.
